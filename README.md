# StepFold · 步骤折叠

DSH（DeepSeek Harness）Web UI 的界面插件：把一轮回答里的**过程步骤**默认收成最近 5 步，点一下展开全部。

装完之后，聊天里那种「思考 / 读文件 / 跑命令」排成一长串的步骤组，每组底部会多一条横条：

```
只看最近 5 步  ←—— 收起时不显示（默认）
显示全部 11 步（还有 6 步）   ←—— 展开读数
```

## 解决的问题

一件事干得久一点，助手的过程步骤就会铺满半屏，真正的回答被顶到下面。你想盯的是「它现在在干嘛」和「它最后说了什么」，不是前面那十行。

所以默认只留最近 5 步：既能看见当前在做什么，又不会被历史步骤挤走。需要复盘的时候，点一下横条看全部。

## 行为细节

- **所有轮次都折**，包括正在运行中的那一轮。想盯着实时进度也没问题——最新几步一直在。
- **答案步永远保留**：最近 5 步里的最后一步通常就是这一轮的答案，不会被折掉。
- **横条只在这一组超过 5 步时出现**，4 步的组不出现，不占地方。
- **每组独立展开**：你展开了第 3 轮，不影响第 7 轮。
- **步骤变了会自动校准**：宿主重新渲染、切换会话、步骤增加或减少，横条都会跟着更新；组里步骤不再超过 5 步时，横条自己消失。
- 折叠**不改变宿主自己的折叠按钮**：一组整体收起时，宿主的那个箭头照样能用；我们的横条只在步骤体展开的状态下显示。

## 安装

在 DSH 里用插件管理器安装这个目录（和 QuickReply 一样的方式）：

```text
plugin_manager install_bundle，target = F:\DSH产出\StepFold
```

安装后：

1. **刷新页面**（Ctrl+Shift+R）。折叠完全在浏览器端实现，不需要重启 DSH。
2. 如果没生效，检查插件列表里 `@local/step-fold` 是否启用。

## 卸载

插件管理器里禁用或删除 `@local/step-fold`。卸载时会把插入的横条、样式和 `<html>` 上的标记类一起清掉，聊天界面恢复原状。

## 技术说明

- 纯客户端插件：`index.js` 是空实现（包需要一个宿主入口），所有逻辑在 `client.js`。
- 不替换宿主任何组件，只用两样东西：
  - 一条注入的 CSS 规则，限制每组步骤体只显示最近 5 步；
  - 一个 MutationObserver，给每组步骤体底部加一条横条（点它给该组打展开标记）。
- 依赖宿主渲染的 `data-step-process` / `data-step-process-body` / `data-step-process-content` 三个语义属性。宿主改版最坏情况是折叠失效、横条不出现，**不会弄坏聊天本身**。
- 不读宿主布局尺寸、不做位置估算；横条是步骤体里的普通兄弟节点。

## 开发

```text
node --check client.js          # 语法
node test/helpers.test.mjs      # 纯函数单测（15 条）
node test/smoke-client.mjs      # 假 DOM 烟测：折叠 / 展开 / 撤按钮 / 卸载
```

`test/smoke-client.mjs` 用最小 DOM 桩子把 `client.js` 跑一遍，验证的是「插件加载不会炸」和「折叠判定对不对」，不是视觉效果——视觉效果只能在浏览器里看。

## 已知限制

- 只对步骤组生效，**不折「思考」正文**（那是另一类节点，宿主自己有折叠）。
- 文案跟随页面语言（中文 / 英文），不跟随每条会话。
- 5 步这个数字是写死的常量（`KEEP_STEPS`），没做成设置项。
